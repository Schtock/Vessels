# Планировщик рейсов судов (диаграмма Ганта)

Одностраничное веб-приложение для планирования рейсов судов и расчёта расходов по тайм-чартеру. Весь код находится в одном файле `index.html`: нет внешних зависимостей и сборки, приложение работает офлайн.

## Запуск

Откройте `index.html` в браузере Chrome, Edge или Firefox двойным щелчком. Сервер и интернет не нужны.

При первом запуске загружаются демонстрационные данные:
- 5 портов: Архангельск, Мурманск, Сабетта, Дудинка, Певек;
- 9 переходов и 2 судна с параметрами тайм-чартера;
- рейс по Северному морскому пути;
- линия «Окончание навигации», привязанная к п. Певек.

## Сохранение данных

Все данные сохраняются **автоматически сразу после ввода**, кнопку «Сохранить» нажимать не нужно. Это касается рейсов, портов, переходов, судов, линий, цен на топливо, параметров судов и размеров панелей.

- **Хранилище браузера** (`localStorage`, ключ `vesselGanttPlanner.v1`) — основное место хранения. В строке под заголовком видно, когда данные сохранены в последний раз («✓ Автосохранено в браузере в 14:05:12»). Данные привязаны к браузеру и к расположению файла `index.html`: откройте тот же файл в том же браузере, и данные будут на месте.
- **💾 Сохранять в файл…** (только Chrome и Edge) — выберите файл `.json` на диске, и каждое изменение будет автоматически записываться и в него. После перезапуска браузера нажмите «Возобновить автосохранение в …»: браузер требует подтвердить доступ к файлу. **📂 Открыть файл…** загружает данные из такого файла и продолжает сохранять изменения в него.
- **Экспорт/Импорт JSON** — ручное сохранение в файл и загрузка из файла, например для переноса на другой компьютер или резервной копии.

Если браузер запрещает хранение (приватный режим, запрет данных сайтов, просмотр файла во встроенном окне другой программы), появляется жёлтое предупреждение. В этом случае используйте «Сохранять в файл» или «Экспорт JSON».

## Справочники (левая панель)

Нормативы грузовых операций и времена переходов задаются **только в справочниках**, в маршруте рейса они выводятся для информации. Запас времени задаётся в рейсе, отдельно для каждого порта.

| Вкладка | Что задаётся |
|---|---|
| **Порты** | название; нормативы погрузки и выгрузки (сут.); **суд. краны** — грузовые операции выполняются судовыми кранами |
| **Переходы** | порт отправления, порт назначения, время перехода (сут.) |
| **Суда** | название, цвет |
| **Линии** | вертикальные линии-дедлайны: подпись, цвет, дата/время и, если нужно, **порт** |

- Дробные значения вводятся через запятую или точку: `1,5` = `1.5`.
- **Переход A→B по умолчанию действует и в обратную сторону (B→A).** Если обратное время другое, нажмите «задать отдельно» под строкой перехода.

## Рейс (вкладка «Рейс»)

1. **«+ Новый»** — выберите судно и дату/время начала.
2. **«+ Добавить порт»** — порты добавляются по порядку. Порядок меняется перетаскиванием за `⋮⋮`, удалить порт — кнопка ✕.
3. У каждого порта выбирается **операция** и при необходимости **запас** в сутках:
   - погрузка;
   - выгрузка;
   - погрузка + выгрузка (сначала выгрузка);
   - без операций (заход).

   **Запас** (очередь, непогода) вводится в маленькое поле «запас … сут.» под портом. По умолчанию оно пустое, то есть запаса нет, поэтому при заходе без операций время само не добавляется. Запас ставится сразу по приходу в порт, до грузовых операций, и на графике показывается заштрихованным блоком.
4. Под портом отображаются маленькие информационные метки:
   - длительность погрузки и выгрузки;
   - «судовые краны»;
   - время прихода и отхода;
   - статус дедлайна, например «✓ Окончание навигации: запас 2,17 сут.».

   Между портами показывается метка «↓ переход N сут.».
5. Если перехода нет в справочнике, появляется жёлтая метка со ссылкой **«задать время»**. Она добавляет переход в справочник, открывает вкладку «Переходы» и ставит курсор в поле времени.

**«Копия»** создаёт копию рейса, которая начинается в момент окончания исходного.

## Фактическое движение судна (вкладка «Факт»)

План строится по справочникам, а факт вносится датами по мере прохождения **контрольных точек**. Для каждого порта маршрута набор точек зависит от операции:

| Операция в порту | Контрольные точки |
|---|---|
| Погрузка | приход → начало погрузки → окончание погрузки → отход |
| Выгрузка | приход → начало выгрузки → окончание выгрузки → отход |
| Погрузка + выгрузка | приход → начало выгрузки → окончание выгрузки → начало погрузки → окончание погрузки → отход |
| Без операций (заход) | приход → отход |

Приход в первый порт считается началом рейса, отход из последнего — окончанием рейса. Интервал «отход → приход» — это переход, «приход → начало операций» и «окончание операций → отход» — стоянка/ожидание.

Как вносить:
- откройте вкладку **«Факт»** и выберите рейс;
- у каждой точки показано плановое время; введите фактическое дату и время или нажмите **«сейчас»**, ✕ очищает значение;
- рядом с введённой датой появляется отклонение от плана: «опоздание 6 ч», «раньше 2 ч» или «по плану» (в пределах 30 минут);
- если время точки раньше предыдущей отметки, поле подсвечивается и выводится предупреждение.

**Прогноз.** Пока рейс не завершён, все ещё не отмеченные точки прогнозируются как план плюс текущее отклонение. Текущее отклонение — это разница между фактом и планом у последней отмеченной точки. Если следующая точка по такому прогнозу уже должна была наступить, а отметки нет, отклонение считается по текущему моменту — то есть растёт, пока событие не отмечено. По прогнозу же проверяется линия окончания навигации: «Прогноз: отход из п. Певек … — до линии остаётся N сут.» или «позже линии на N сут.».

**На графике** факт показывается тонкой полосой под планом того же рейса:
- цвета те же, что у плана: погрузка зелёная, выгрузка синяя, переход цвета судна, стоянка/ожидание серая;
- этап, который идёт сейчас (начало отмечено, окончание ещё нет), рисуется бледной полосой до текущего момента;
- тёмные риски — моменты отмеченных событий;
- пунктир с ромбом — прогноз окончания рейса; в подписи рейса указано отклонение прогноза («прогноз +6 ч»);
- при наведении — фактические даты, длительность и длительность по плану.

**Под графиком** появляется таблица «План / факт по контрольным точкам»: событие, план, факт или прогноз, отклонение, а над ней — сводка с последней отметкой, отклонением и прогнозом окончания рейса.

При копировании рейса факт не копируется. В демо-данных для примера отмечены приход в Архангельск (+2 ч) и начало погрузки (+6 ч), погрузка идёт.

## Линия окончания навигации с привязкой к порту

Если у линии выбран порт (например, Певек), проверяется, что **судно уходит из этого порта до указанной даты и времени**. Отход — это окончание всех операций в порту.
- Если всё в порядке, у порта в маршруте и под таблицей рейса показывается зелёная метка с оставшимся запасом времени.
- Если судно опаздывает, показывается красное предупреждение с размером опоздания. На графике стоянка в порту обводится красной рамкой.

Линия без порта проверяет, что рейс заканчивается до даты.

## Листы: «Планирование», «График», «Расходы»

Над основной областью — три вкладки:

- **«Планирование»** — рабочее место: слева панель редактирования (рейс, факт, справочники), справа **превью графика** и таблица выбранного рейса. Все изменения сразу видны на превью.
- **«График»** — только диаграмма Ганта на всю ширину и высоту окна, без панели редактирования и таблиц. Удобно для просмотра и показа плана. Масштаб, ширина дня, высота строк, «К сегодняшнему дню» и «+ Линия-дедлайн» доступны и здесь. Щелчок по рейсу выделяет его, **двойной щелчок** открывает рейс в «Планировании».
- **«Расходы (тайм-чартер)»** — расчёт расходов (см. ниже).

Открытая вкладка запоминается.

## График рейсов

- У каждого судна своя строка. Рейсы, пересекающиеся по времени, раскладываются по дорожкам внутри строки.
- Ось — календарные даты. Масштаб переключается между «Дни» и «Недели».
- Обозначения (они же в легенде под графиком):
  - **погрузка** — зелёный блок;
  - **выгрузка** — синий блок;
  - **переход** — полоса цвета судна;
  - **запас** — штриховка цвета операции;
  - **заход без операций** — ромб;
  - **сегодня** — красная линия;
  - **дедлайн** — пунктирная линия.
- При наведении на блок показываются точные даты начала и окончания. В «Планировании» щелчок по блоку открывает рейс для редактирования.
- В «Планировании» под графиком — таблица выбранного рейса с итогом.

## Изменение размеров блоков

- **Ширина левой панели** — потяните за вертикальный разделитель между панелью и графиком.
- **Высота превью графика** в «Планировании» — потяните за полоску под графиком. На листе «График» высота подстраивается под окно автоматически.
- **Ширина дня** и **высота строк** графика — ползунки «Ширина» и «Высота строк» на панели инструментов.
- Двойной щелчок по разделителю или кнопка **«Сбросить размеры»** возвращают размеры по умолчанию.

Размеры тоже сохраняются автоматически.

## Лист «Расходы (тайм-чартер)»

Третья вкладка над основной областью. На ней задаются:
- **цены на топливо** — тяжёлое (HFO/IFO) и дизельное (MGO/ДТ) за тонну, а также валюта (USD, EUR, RUB);
- **параметры судов** — ставка фрахта за сутки и расход тяжёлого и дизельного топлива (т/сут.) в трёх режимах:
  - **на переходе** — время в пути;
  - **на стоянке** — запас (очередь, непогода) и грузовые операции береговыми средствами;
  - **при грузовых операциях судовыми кранами** — операции в портах с отметкой «Суд. краны».

Для выбранного рейса рассчитываются:
- фрахт = ставка × сутки рейса;
- расход топлива и его стоимость по каждому режиму;
- итого по топливу, общие расходы по рейсу и средние расходы в сутки.

## Экспорт и печать

- **Экспорт PNG** — график с легендой в двойном разрешении.
- **Печать / PDF** — альбомная ориентация A4. Печатается открытая вкладка: «Планирование» — график с таблицей рейса, «График» — только график, «Расходы» — лист расходов. Для PDF выберите «Сохранить как PDF». Включите «Фоновая графика», чтобы сохранились цвета.
- **Демо-данные** — заменяет текущие данные демонстрационными (после подтверждения).

## Правила расчёта рейса

Для каждого порта маршрута по порядку:

1. Для всех портов, кроме первого, считается **переход** из предыдущего порта. Время берётся из справочника: сначала прямое направление, затем обратное. Если значения нет, переход считается равным 0 и выводится предупреждение.
2. **Запас**, заданный для этого порта в рейсе (если задан).
3. **Грузовые операции** по нормативам порта (при «погрузка + выгрузка» — сначала выгрузка).

Время считается непрерывно, сутки по 24 часа, в местном времени браузера.

Файлы прежних версий загружаются автоматически:
- версия 1: время перехода, введённое в рейсе вручную, добавляется в справочник переходов;
- версия 2 (запас хранился в справочнике портов): запас переносится в рейсы, в каждый заход в этот порт с грузовыми операциями; заходам без операций запас не назначается.

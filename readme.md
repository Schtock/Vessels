# Планировщик рейсов судов (диаграмма Ганта)

Одностраничное веб-приложение для планирования рейсов судов. Весь код находится в одном файле `index.html`: нет внешних зависимостей и сборки, приложение работает офлайн.

## Запуск

Откройте `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari), например двойным щелчком. Сервер и интернет не нужны.

При первом запуске загружаются демонстрационные данные: 4 порта (Архангельск, Мурманск, Сабетта, Дудинка), 5 переходов, 2 судна, один рейс и линия «Окончание навигации».

## Интерфейс

Слева находится панель редактирования с вкладками, справа — график и таблица выбранного рейса.

### Справочники

| Вкладка | Что задаётся |
|---|---|
| **Порты** | название, норматив погрузки (сут.), норматив выгрузки (сут.) |
| **Переходы** | порт отправления, порт назначения, время перехода (сут.) |
| **Суда** | название, цвет |
| **Линии** | вертикальные линии-дедлайны: дата/время, подпись, цвет |

- Длительности могут быть дробными, запятая и точка равноправны: `1,5` = `1.5`.
- **Переход A→B по умолчанию действует и в обратную сторону (B→A).** Если время в обратную сторону другое, нажмите «задать отдельно» под строкой перехода или добавьте переход B→A вручную. Точное направление всегда важнее обратного.
- При удалении порта удаляются связанные с ним переходы, а порт убирается из маршрутов. При удалении судна удаляются его рейсы. Перед удалением приложение спрашивает подтверждение.

### Рейс (вкладка «Рейс»)

1. Нажмите **«+ Новый»**, выберите судно и дату/время начала.
2. Добавьте порты по порядку кнопкой **«+ Добавить порт»**.
3. Для каждого порта выберите операцию:
   - **Погрузка** — длительность берётся из норматива погрузки порта;
   - **Выгрузка** — из норматива выгрузки;
   - **Погрузка + выгрузка** — сначала выгрузка, затем погрузка (два блока подряд);
   - **Без операций (заход)** — на графике отмечается ромбом, длительность 0.
4. **Запас** (очередь, непогода) задаётся в сутках для каждого порта. Он ставится сразу по приходу в порт, до грузовых операций, и показывается отдельным заштрихованным блоком того же цвета, что и операция.
5. Порядок портов меняется перетаскиванием за значок `⋮⋮` или кнопками ▲ ▼. Порт удаляется кнопкой ✕.
6. **Время перехода** между портами подставляется из справочника автоматически. Его можно переопределить для конкретного рейса: введите значение в поле, а ссылка «вернуть из справочника» отменит переопределение.
   Если перехода нет в справочнике, появляется жёлтое предупреждение с полем ввода. Введённое значение сразу используется в расчёте, а ссылка «сохранить в справочник» добавит его в справочник переходов.

Кнопка **«Копия»** создаёт копию рейса, которая начинается в момент окончания исходного. Это удобно для планирования следующего рейса того же судна.

Под маршрутом показываются итоговая длительность и дата окончания, а также предупреждения: нет перехода, не задан норматив, рейс заканчивается позже линии-дедлайна.

### График

- У каждого судна своя строка. Если рейсы одного судна пересекаются по времени, они раскладываются по дорожкам внутри строки.
- Горизонтальная ось — календарные даты. Масштаб переключается кнопками **«Дни» / «Недели»**. Выходные дни в масштабе «Дни» подсвечены.
- Обозначения (они же приведены в легенде под графиком):
  - **погрузка** — зелёный блок;
  - **выгрузка** — синий блок;
  - **переход** — узкая полоса цвета судна;
  - **запас** — штриховка цвета соответствующей операции;
  - **заход без операций** — ромб;
  - **сегодня** — красная линия;
  - **дедлайн** — пунктирная линия с подписью.
- На блоках выводятся порт, операция и длительность, если хватает места. При наведении показываются точные дата/время начала и окончания и длительность.
- Щелчок по блоку открывает рейс для редактирования. Выбранный рейс обведён пунктирной рамкой.
- Кнопка **«+ Линия-дедлайн»** добавляет вертикальную линию, например «Окончание навигации».
- Названия судов закреплены слева при горизонтальной прокрутке.

### Таблица рейса

Под графиком показывается таблица выбранного рейса: этап, порт или участок, начало, окончание, длительность в сутках и часах. Внизу — итог по рейсу с разбивкой: в пути, грузовые операции, запас.

## Данные

- **Автосохранение** — все изменения сразу сохраняются в `localStorage` браузера под ключом `vesselGanttPlanner.v1`. Данные привязаны к браузеру и к расположению файла, поэтому для переноса на другой компьютер используйте экспорт.
- **Экспорт JSON** — скачивает все данные (справочники, рейсы, линии, настройки) в файл.
- **Импорт JSON** — загружает данные из файла и заменяет текущие (после подтверждения).
- **Экспорт PNG** — сохраняет график вместе с легендой картинкой в двойном разрешении.
- **Печать / PDF** — открывает печать браузера. Страница уже настроена на альбомную ориентацию A4 и печатает только график и таблицу рейса. Чтобы получить PDF, выберите принтер «Сохранить как PDF». Если снят флажок «Фоновая графика», браузер может не напечатать цвета — включите его в настройках печати. Для длинных планов удобнее масштаб «Недели».
- **Демо-данные** — заменяет текущие данные демонстрационными (после подтверждения).

### Формат JSON

```json
{
  "version": 1,
  "ports":     [{ "id": "…", "name": "Архангельск", "load": 2, "unload": 1.5 }],
  "legs":      [{ "id": "…", "from": "<id порта>", "to": "<id порта>", "days": 1.5 }],
  "ships":     [{ "id": "…", "name": "Северное сияние", "color": "#e8590c" }],
  "voyages":   [{
    "id": "…", "name": "Рейс 1", "shipId": "<id судна>", "start": "2026-09-25T08:00",
    "stops": [{ "id": "…", "portId": "<id порта>", "op": "load|unload|both|call",
                "reserve": 0.5, "transit": null }]
  }],
  "deadlines": [{ "id": "…", "date": "2026-10-19T00:00", "label": "Окончание навигации", "color": "#c92a2a" }],
  "settings":  { "scale": "day|week", "sel": "<id выбранного рейса>", "tab": "voyage" }
}
```

`transit` у порта маршрута — время перехода из предыдущего порта, введённое вручную (`null` — брать из справочника).

## Правила расчёта

Для каждого порта маршрута по порядку:

1. Для всех портов, кроме первого, считается переход из предыдущего порта. Его время берётся из ручного значения в рейсе, иначе из справочника: сначала прямое направление, затем обратное. Если значения нет, переход считается равным 0 и выводится предупреждение. Два одинаковых порта подряд дают переход 0.
2. Запас порта.
3. Грузовые операции по нормативам порта (при «погрузка + выгрузка» — сначала выгрузка).

Время считается непрерывно, в сутках по 24 часа, в местном времени браузера.
